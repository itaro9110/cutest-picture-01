A Python program that draws the cutest picture it can: a fluffy cream kitten with a flower crown, huge amber eyes and a pink bow, hugging a tiny plush bunny. It runs on the standard library only and always writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
