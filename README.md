A Python program that draws the cutest picture it can: a baby red panda cub in a mint knitted scarf, huge brown eyes and a banded tail, hugging a tiny green frog with a daisy on its head. Every shape is a signed-distance field painted by hand — no image files, no network, no Pillow. It runs on the standard library only and always writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
